The gap it fills

One checklist per project isn't enough

YouTrack's built-in checklist — and the checklist tools most teams know from Jira — scope templates to a project. Every issue in that project gets the same list, whether it's a one-line typo fix or a three-sprint epic.

Project-level checklist

  • One template for the whole project
  • Bugs and Stories see identical items
  • Irrelevant steps get skipped or ignored
  • Teams stop trusting the checklist
→

Checklist Pro

  • Templates scoped to a specific issue type
  • A fallback "any type" template still works
  • Required vs. optional items, marked clearly
  • Evidence links attached right on the item

What's included

Built for how issues actually get worked

All data stays inside your own YouTrack instance — no external database, no third-party server in the loop.

Issue-type templates

Create a template once, scope it to Bug, Story, Task, or leave it open to any type.

Required vs. optional

Mark items mandatory so it's obvious what actually blocks a checklist from being "done."

Evidence links

Attach a link to a PR, doc, or screenshot directly on the item that needs it.

Live progress

A per-checklist progress bar, plus a count of required items still outstanding.

Drag to reorder

Rename, reorder, and edit items inline. Changes autosave a moment after you stop typing.

No external database

Checklist and template data lives in YouTrack's own storage. Uninstall cleanly, anytime.

Getting started

Live in a project in about five minutes

1

Install the app

From the YouTrack Marketplace, or upload the package directly from your Apps admin page.

2

Attach it to a project

Turn it on for the projects that want it — no instance-wide commitment required.

3

Build your first templates

Open Project Settings → Checklist Templates and set up one per issue type that needs it.

4

Apply on any issue

The right templates show up automatically, filtered to that issue's type.
